TITLE: 授權漫遊：把消費旅程交給 Agent 之前，先決定它能走多遠
STYLE: 冷靜史詩科幻 · 長鏡頭、低語的艙內對話與一層一層開啟的權限
## 序章｜提問
~ 2026 年。深空貨運艦「遠行號」，航行第三百一十二天。艙內很安靜，只有維生系統低低的嗡鳴。
艦長林准坐在指揮台前，看著一整面牆的消費者訊號。
它們不再是關鍵字。
「最近常熬夜，想找適合長期補充的營養品。」
「天氣忽冷忽熱，臉頰乾、T 字又出油，該怎麼搭配保養？」
「替八個人的聚會準備食物和用品。」
今天的消費者，越來越少用品牌熟悉的方式表達需求。這些提問同時包含目的、限制、偏好和情境，已經超過一個關鍵字、一張商品頁或一則廣告能處理的範圍。
林准轉向艦上的 AI 代理。它沒有名字，船員都叫它「領航」。
「你能接手多少？」
領航沒有立刻回答。它在等一件事：授權。
## 第一章｜沒有人接手的那一步
~ 長鏡頭。艦艙的走廊延伸到看不見的盡頭，兩側是一扇一扇關著的艙門，每一扇門後都是一個系統：電商、CRM、客服、門市、內部系統。
對企業來說，難題也變了。品牌擁有大量商品、會員資料、專業知識和內容資產，卻分散在一扇一扇關著的門後。消費者期待即時、個人化的服務，企業卻沒辦法替每一位顧客配一名專員；行銷團隊能快速產出內容，卻未必能把內容、推薦、服務和交易連成一條流暢的路。
內容產出早就不是瓶頸。卡住的，是內容、推薦和交易之間沒有人接手——顧客問完問題，品牌沒有下一步。
這也是 AI Agent 開始進入行銷現場的原因。
林准知道，對行銷實務來說，選哪一個模型不是決定因素；重點是自主程度：這套系統被允許讀寫哪些系統，以及在沒有人介入的情況下，能連續走幾步。只能產出推薦文案的，和能依顧客資料調整建議、更新購物車、觸發 CRM 或安排人工接手的，差別就在這裡。
> AI Agent 對行銷真正的影響，是把分散在搜尋、推薦、客服、CRM 與交易的能力，組合成能持續回應、並採取下一步行動的品牌執行層。
企業真正要盤點的，是消費旅程裡有哪些任務，可以在清楚的權限下，交給 AI 代表品牌往前推進。
林准調出三份航行紀錄：零售、美妝、保健品。同一套技術，在三種行業結構下，給出了三種不同的答案。它們都可以放在同一條 Agent 權限光譜上看：從觀察與理解需求、提出推薦，到替消費者做出部分決策，最後才是直接採取行動。
## 第二章｜零售：把一個生活任務，變成一個購物籃
~ 第一份紀錄亮起。畫面上，一個人對著手機說：「替八人晚餐聚會準備食物。」
零售的 Agentic AI 發展得最快。任務清楚，資料充足，行動結果也容易衡量。
傳統電商建立在搜尋、瀏覽、商品頁和購買的流程上。消費者如果輸入「替八人晚餐聚會準備食物」，系統得理解人數、預算、品類搭配、庫存和配送，光靠關鍵字很難完成。對 Walmart 這樣的全通路零售商來說，新的競爭已經從商品有沒有上架，延伸到能不能把一個生活任務，轉譯成一個完整的購物籃。
Walmart app 裡內建了生成式 AI 智慧購物助理 Sparky。它先統整商品評論、比較選項、回答問題，再依場合提出跨品類的建議；後來能力擴展到備餐規劃、個人化補貨、自動重新購買和店內體驗。
它的工作流程覆蓋了從理解目標到成立訂單的整條鏈：接收顧客目標，理解限制和偏好，檢索商品、評論、價格和庫存，拆解採買任務，建立購物籃，再銜接帳號、結帳和履約。Sparky 也被納入 Walmart 的四大 Super Agents 架構，和服務員工、供應商、開發者的 Agent 共用企業能力——它的定位，早已超過單一的聊天功能。
Walmart 的公開資料指出：Sparky 的週活躍用戶在 2026 年第一季較前一季成長逾一倍；使用者的平均訂單金額，約比未使用者高 35%；透過 Sparky 購買的商品件數，也曾較前一季成長超過四倍。對話式導購，已經開始連接可觀察的交易行為，而不只停在互動和流量指標。
更值得注意的是，Sparky 正在測試「贊助提問」（Sponsored Prompt）。消費者討論能量飲料時，系統可能顯示「比較含糖量」之類的建議問題，其中就包含廣告主贊助的提問，回答之後再連到商品廣告。零售媒體的布局，有機會從搜尋結果頁，往前移到需求定義和商品比較的階段。
對品牌來說，被看見的條件變了。未來的曝光，除了取決於搜尋排名、素材和出價，也取決於產品資料能不能被 AI 理解：屬性有沒有結構化？使用情境清不清楚？庫存和價格是不是即時？評論和 Q&A 夠不夠支持比較？品牌要爭的，是在某個任務和限制下，產品有沒有被 Agent 放進候選答案。
## 第三章｜美妝：把模糊的「適合我」，變成可以服務的資料
~ 第二份紀錄。一面鏡子前，一位旅客把臉湊近一台小小的檢測儀。
美妝的難題，來自個人差異。膚質、膚色、季節、生活環境和使用偏好，都會改變每個人的答案；大量的 SKU 又讓人很容易陷入搜尋疲勞。K-Beauty 走向全球之後，語言和膚色差異又被放大。
韓國最大的美妝零售巨頭 Olive Young，服務來自 189 個國家的消費者和觀光客。傳統上，要維持一致的體驗，需要大量的門市人員；Olive Young 選擇導入 AI agent 來賦能門市人員，提升服務品質和效率。
它把購物旅程拆成四段：診斷與搜尋、比較、購買、售後，並在前兩段導入膚質檢定、顏色推薦和髮質檢測。消費者透過影像或顯微設備取得水分、油分、毛孔、膚色、頭皮等資料，系統據此判定類型、推薦對應品類；門市的美容顧問再用螢幕設備，結合檢測結果、預算和偏好篩選產品，必要時帶顧客走到正確的貨架。
機器處理可以標準化的感知與比對，店員把時間放在解釋、建議和建立信任。
> 使用膚質檢定的消費者，最終購買轉換率為 73%；未使用者為 53%。
這個差距說明，面對大量的美妝選項，消費者真正需要的是一個更有把握的判斷依據。Olive Young 把肌膚檢測、商品推薦、店內導航和美容顧問串在一起，讓原本模糊的「哪一款適合我」，一步一步變成可理解、可比較、也更容易行動的答案。AI 負責資料判讀和初步篩選，門市人員依預算、偏好和使用習慣給出更貼近情境的建議。兩者接力，降低了選擇壓力，也提高了下決定的信心。
可以預見，AI 美容顧問的下一步，會從購買前的診斷與推薦，延伸到購買後的持續陪伴——這正是 Agent 能接手的區間。在取得顧客同意的前提下，串聯歷次檢測結果、購買紀錄、使用回饋和季節情境，Agent 可以主動做幾件事：依上次檢測和用量推算產品用完的時間，在回購點之前備好購物車；偵測到換季或顧客回報膚況變差時，提出保養組合的調整建議；直接替顧客預約門市顧問的檢測時段，並把歷次資料先交到顧問手上。
當一次性的個人化體驗，變成可以延續的服務關係，AI 的角色就從協助成交，進一步成為品牌經營會員忠誠和長期價值的核心能力。
## 第四章｜保健品：能回答多少，取決於品牌敢授權多少
~ 第三份紀錄。畫面很暗。一個人深夜坐在床邊，對著手機打字，又刪掉，又打字。
保健營養品市場面對一組難解的矛盾：需求越來越個人化，資訊風險也跟著升高。面對複雜的成分、劑量、生活型態和產品組合，消費者往往很難自己判斷；品牌則必須在提供健康教育的同時，兼顧購買轉換和長期回購。
美國醫療級保健品牌 Thorne 委託第三方做的消費者調查顯示：57% 的受訪者認為網路上的補充品資訊彼此矛盾，61% 希望獲得個人化的指引，另有 43% 在過去一個月曾用 AI 或 ChatGPT 尋求健康建議。需求已經存在；品牌如果不能及時給出可信的回應，消費者自然會轉向通用型 AI 找答案。
為了回應這個需求，Thorne 在 2026 年初推出生成式 AI 健康顧問 Taia。它的知識基礎，來自品牌累積四十多年的臨床研究、專家知識和教育內容，能針對腸道、皮膚、疲勞等問題提供補充品和生活型態建議。消費者輸入問題，系統先判讀需求，再檢索品牌知識庫，形成個人化回覆，並引導使用者進一步探索相關產品。
> 上線六個月：累計處理超過 20 萬則訊息，提出逾 35 萬項建議；使用者回饋 94% 為正面；使用 Taia 的顧客，平均客單價高出約 8%。
Thorne 回應的是資訊判斷的缺口；德國機能保健品牌 BRAINEFFECT，則把對話嵌進了購物流程。
傳統電商在促銷檔期常遇到 EDM 開信率偏低、折扣競爭加劇。BRAINEFFECT 和對話商務平台 charles 合作，把 WhatsApp 從單向發訊息的管道，變成能理解需求、推進購買的互動介面。
消費者進入聊天室，AI Agent 透過多輪對話了解他在睡眠或專注力上的需求，提出個人化的保健品組合。過程中穿插真人錄製的語音訊息和健康知識內容，一點一點建立信任；消費者確認方案之後，系統直接送出一個包含專屬折扣、商品已經組好的 Shopify 一鍵購物車連結，縮短從諮詢到結帳的距離。
競爭的焦點，從單品折扣轉向個人化組合和對話服務。黑色星期五期間，它的對話轉換率達到 25%；平均每開啟一個 WhatsApp 對話（Revenue per Recipient，RPR）賺得 14.50 歐元，折合新台幣約 534 元，超過業界平均七倍。對話式導購有機會同時改善轉換效率，並提高每位顧客帶來的營收貢獻。
兩個品牌，一個從知識服務切入，一個從對話商務切入，共同帶出一個關鍵判斷：衡量 Agent 的成熟度，除了看它能不能給出專業、有用的回答，更要看它能不能在清楚的安全邊界內，完成下一步行動。
## 第五章｜四個變化
~ 林准關掉三份紀錄，在航行日誌上寫下四行字。
這些案例在 Agent 的設計上，自主權並不平均，散落在光譜的不同位置。但它們都看見了共同的變化。
第一，從回答問題，走向完成任務。生成式 AI 能回答「哪款適合我」；Agentic 流程會繼續檢索資料、比較選項、建立建議、串接系統，推動購買、回購或人工服務。衡量方式也得跟著改：除了互動量和內容產能，企業更該追蹤任務完成率、轉換、客單價、人工升級率、錯誤率和顧客滿意度。
第二，消費者開始把一部分決策委託出去。過去的個人化行銷，是品牌依分眾決定對誰說什麼；當消費者把資料整理、選項比較和部分決策交給 Agent，行銷就進入了代理人經驗的時代。品牌同時要服務兩個對象：做最終感受和判斷的人，以及替他整理資訊、篩選方案的 AI。產品資料、專業知識和可驗證的證據，都成了品牌溝通的一部分。
第三，行銷的節奏可以突破檔期。傳統行銷以檔期和素材為節奏，Agent 則在每一次提問、購買、使用和回購之間持續工作。沒有記憶、CRM 和交易資料，Agent 只能完成一次性的推薦；能在顧客同意下保留狀態、依新訊號調整下一步，才可能形成長期關係。行銷、客服、商務和會員營運的界線，也會跟著變模糊。
第四，競爭優勢從模型轉向企業能力。基礎模型的取得成本持續下降，真正難以複製的，是乾淨的顧客資料、結構化的商品資訊、品牌專業知識、即時的庫存與交易連接，以及一套決定 Agent 何時觀察、推薦、決策、行動、或轉交人類的治理規則。
林准在第四行下面加了一句註記：
> Agent 會放大企業既有的能力，也會一併放大資料混亂、流程斷裂和權責不清。
商品屬性沒填齊，Agent 就會把不含該成分的品項推進購物籃；退貨規則散在三個系統，Agent 就只能把顧客轉回客服排隊。
## 第六章｜四道艙門
~ 指揮台上出現四個按鈕，由左至右。領航靜靜等著。
四個案例放在一起看，企業導入 Agent 不需要一步到位。更實際的做法，是先釐清某項任務需要 Agent 擁有哪一層權限，再依風險逐步開放。
> 第一道門・觀察／理解：讀取、整理資料，辨識需求與情境。企業要確認：資料來源可不可靠？有沒有取得必要的同意？
> 第二道門・推薦：比較與排序選項，提出商品、內容或服務建議。企業要確認：推薦規則、知識來源和錯誤容忍度清不清楚？
> 第三道門・決策：依既定條件替使用者選擇下一步。企業要確認：決策能不能撤回？什麼時候需要人工確認？
> 第四道門・行動：寫入系統、建立購物車、觸發 CRM、預約、下單或啟動履約。企業要確認：可執行範圍、金額限制、稽核與回復機制是否明確？
放回四個案例：Olive Young 和 Thorne 主要在「觀察／理解」和「推薦」；BRAINEFFECT 已經把推薦接到預先組好的購物車和交易；Walmart 則把 Agent 延伸到跨品類任務拆解、建立購物籃和履約。
這些差異，不宜只被解讀成技術成熟度的高低，更反映了不同產業對風險、責任和可逆性的選擇。
> Agent 的成熟度，不等於自主權越高越好。
## 第七章｜四個問題
~ 林准先打開了一份檢查表。
企業不必先在「要不要導入 AI Agent」之間二選一。更務實的起點，是找出顧客旅程裡高頻、高摩擦、需要整合多項資訊、而且最後必須採取下一步的任務。它可能是保健品的商品發現和補貨提醒、美妝門市的診斷與推薦，也可能是零售的聚會採買和跨品類購物籃。任務能被清楚描述，投資範圍、資料需求和 KPI 才能被定義。
檢查表上有四個問題。
第一，哪一個消費旅程裡的摩擦，值得先被解決？盤點消費者反覆詢問、員工重複處理、轉換容易中斷的節點，建立現況基準，再挑一個能在一個檔期或一季內看到結果的任務。
第二，Agent 可以用哪些資料？商品、內容、會員、庫存和交易資料需要結構化，也要釐清同意、用途和保存期限。模型很快就能採購，資料準備往往才是時程的瓶頸。
第三，Agent 可以做到哪一層？明確劃分觀察理解、推薦、決策、行動四種權限，為不同情境設定限制和回復機制。錯誤成本低、容易撤回的工作，可以提高自主程度；涉及健康、敏感資料、重大支出或品牌聲譽時，應保留人工確認。
第四，誰對 Agent 的輸出和行動負責？品牌語氣、健康聲明、隱私、幻覺、廣告揭露、人工升級和稽核紀錄，都需要清楚的負責人員和決策規則。
## 終章｜航向
~ 長鏡頭。遠行號緩緩轉向。林准按下了前兩個按鈕，第三個按鈕旁亮起一行小字：需艦長確認。領航回應：「收到。我會在需要時停下來問你。」
從零售、美妝到保健品，共同的方向是：AI 正在從內容與分析工具，走進顧客旅程的執行層。
四個案例的自主程度和成效強度並不一致；而這種不一致，本身就是企業制定策略的重要線索。值得優先投入的，是那些目標清楚、資料可得、風險可控、能被衡量，並且真的能替顧客減少決策摩擦的任務。
