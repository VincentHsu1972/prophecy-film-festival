TITLE: 第二位乘客：在人與 AI 之間，體驗只被問了一半
STYLE: 太空歌劇 · 星際字卡開場、通譯機器人穿梭兩個世界的冒險史詩
NOTE: 理財顧問 Wendy 為原文中的情境人物；電商退換貨 AI 客服 Agent 的導入經驗，為原文作者團隊親身見證，非虛構角色的經歷。通譯機器人「澄言」與星際艦隊的意象為改編所加。
## 字卡｜序章
> 這是一個人與 AI 開始共同做決定的年代。
> 二十年來，體驗設計的星圖上只畫著一種旅人：人類。
> 如今，一種新的乘客登上了艦橋。它沒有眼睛，沒有情緒，卻握有決策的權力。
> 而大多數的艦隊，還沒有為它準備好座位。
## 篇章 I｜深夜裡的核對
~ 晚上八點。一間財富管理辦公室，燈只剩一半還亮著。艦隊的通譯機器人「澄言」在走廊上巡航，專門替人類和機器傳話。
澄言停在一張辦公桌旁。
理財顧問 Wendy 盯著螢幕，游標停在「重新產生摘要」的按鈕上。這是她今天第四次，把 AI Agent 剛剛吐出來的客戶資產配置報告，重新拉開 Excel，手動核對一遍。
這套 Agent 的技術能力其實不差。它能在幾秒內彙整客戶的股票、基金、保單配置，理論上該省下 Wendy 大半天的作業時間。但上線三個月，使用率遠低於預期。顧問們寧可自己查，也不敢直接把 Agent 的輸出拿去見客戶。
澄言掃描了那個 Agent。問題很快就找到了：它每次執行任務，都不會告訴顧問自己在做什麼——有沒有存取到最新的資料？有沒有漏掉某個帳戶？現在看到的是不是舊版本？
它像一個悶著頭做事、從不回報進度的新人。動作再快，也沒有人敢把重要的事交給它。
澄言在航行日誌裡寫下：問題不在 Agent 的運算能力，而在它從來沒有被設計成「一個值得被信任的工作對象」。
> 這就是 Agent Experience，AX。
它牽動的不只是 Wendy 這樣的內部員工，還有每一個正在把決策交給 AI 的顧客。
## 篇章 II｜只有一個人在場的星圖
~ 澄言調出艦隊的歷史檔案。二十年來的每一次作戰會議，畫面都長得一樣。
行銷主管打開一份報告：App 的流失漏斗、官網熱圖、會員旅程的掉落點。討論的焦點，永遠是那個拿著手機、坐在電腦前的消費者。
他是 UX 話語體系裡長期以來唯一的主角。從 1990 年代 Donald Norman 在蘋果確立這個概念，到 Nielsen Norman Group 把它系統化成方法論，這門學科從沒被正面質疑過一件事：體驗的主體是誰？答案一直只有一個：真實的人類消費者。
現在，這個前提正在鬆動。
Gartner 在 2022 年提出的 Total Experience（TX）框架，是第一個系統性擴展「體驗主體」的戰略模型：顧客體驗（CX）、使用者體驗（UX）和員工體驗（EX），不是三條平行的航道，而是一個互相牽連的生態系。員工能不能快速拿到正確資訊，直接決定顧客在電話那頭感受到的服務品質。
Gartner 預測，到 2026 年，全球六成大型企業將仰賴 TX 策略來轉型商業模式；Forrester 的研究則印證了它的代價：擁有高品質員工體驗的企業，年均股票回報比同業高出 2.3% 到 3.8%。「體驗設計」從來不只是在設計消費者看到的那個畫面。
在 TX 的時代，「體驗」同時涉及消費者的 UX、員工的 EX，以及高階主管的決策體驗（Decision Experience）。但這三者加起來，仍然只有一種主體：人類。
2025 年之後，一種新的主體駛進了這片星域。
## 篇章 III｜新乘客
~ 艦橋的通訊頻道亮起一則訊號。
2025 年 1 月，雲端託管大廠 Netlify 的執行長 Mathias Biilmann 提出了一個概念：Agent Experience 的邏輯其實很簡單。我們已經有 UX 讓使用者有好的體驗，也有 DX（Developer Experience）讓開發者有清楚的文件；現在，當 AI Agent 成為使用產品的主體之一，我們需要第三個概念——讓 Agent 在互動時，也能有順暢、可預測、可信賴的體驗。
這股趨勢有多大？麥肯錫 2025 年的報告畫出了輪廓：88% 的受訪企業已經在至少一項商業功能裡定期使用 AI，但只有大約三分之一開始規模化。
澄言把這兩個數字並排放在星圖上。一扇奠定未來十年標準的窗口正在打開，而大多數企業還沒意識到：自己現在做的設計決策，將決定日後的基準線——不管是企業內部的工作 Agent，還是顧客直接面對的服務 Agent。
## 篇章 IV｜被壓縮的航程
~ 澄言把航線圖拉遠。Wendy 的信任問題只是冰山一角，更大的變化發生在顧客和品牌之間。
過去二十年，顧客體驗建立在「人主動操作」的邏輯上：有需求，就搜尋；看到廣告，就點擊；遇到問題，就問客服。企業的系統在顧客發出明確的訊號之後才回應。這是指令回應式體驗（Request-Based Experience）。
AI Agent 正把體驗推向另一種模式：代理協作式體驗（Agent-Assisted Experience）。Agent 不只是等指令，而是理解目標、判斷情境、整理選項，在授權範圍內協助完成任務。所以 Agent 不該被簡化成「更聰明的 Chatbot」——Chatbot 解決的是回答問題的效率，Agent 改變的是任務本身怎麼被執行。
以買旅遊產品為例。過去，顧客從搜尋目的地開始，一一比較航班、飯店、評論、保險，再付款、排行程，這是一段充滿資訊負擔的長途航行。在 Agent Experience 裡，顧客也許只要說出預算、日期和偏好，Agent 就能先整理出幾套可執行的方案。大量的搜尋和比較成本，已經被 AI 吸收。
> 這叫做顧客旅程壓縮（Journey Compression）。
這是一個重要的提醒：接觸點（Touchpoint）變少，不代表品牌影響力不重要；反而每一次被 Agent 選中、推薦、呈現的機會，都更關鍵。當 Agent 可能只給顧客三個選項而不是三十個，品牌怎麼被理解、被排序、被信任，就是新的戰場。
壓縮也在改變介面的形態。過去的數位介面大多固定——首頁怎麼排、表單有哪些欄位，都由企業預先設計。AI 之後，介面開始因人、因情境、因任務而變：同一個金融服務，對新客戶呈現簡化的方案比較，對既有會員直接顯示資產狀況和到期提醒。這就是生成式使用者介面（Generative UI）的商業意義：介面從固定流程，變成動態的服務入口。
企業理解顧客的方式也在變。過去依賴顧客主動表達意圖：搜尋關鍵字、瀏覽商品、加入購物車。現在 AI 讓企業能理解更多還沒說出口的訊號——反覆查看某類商品、購買週期接近、在流程裡停留過久——它們可能代表需求正在形成、疑慮正在累積。
競爭因此從需求捕捉（Demand Capture），轉向需求預測（Demand Anticipation）：從等顧客開口，到在開口之前就先理解他的狀態。
但這裡有一條很細的界線。同一種預測能力，可以拿來更早打擾顧客，也可以讓 Agent 懂得節制：知道什麼時候該提醒、什麼時候該協助、什麼時候該沉默。這也是 Agent Experience 和傳統行銷自動化最大的差異——傳統自動化追求觸發與轉換，Agent Experience 必須同時理解情境、任務、風險和人的感受。
## 篇章 V｜沒有按鈕可看的乘客
~ 澄言試著用人類的方式和那位新乘客溝通。它微笑、它放慢語速、它把畫面調得更好看。新乘客完全沒有反應。
理解 AX 的概念不難；難的是在現場做設計決策時，得轉換一整套根深柢固的直覺。UX 的訓練核心是同理心：設身處地感受使用者的情緒和挫折。這套訓練，對設計 Agent Experience 幾乎沒有直接的用途。
Agent 沒有情緒，不會因為頁面好看而多停留。但它會因為 API 回應不穩定而中斷任務，會因為指令不夠明確，在幾十個步驟之後偏離初衷。
UX／UI 業界的重要智庫 Nielsen Norman Group 在 2026 年的 State of UX 報告裡說得更直接：2026 年，信任將是 AI 體驗最核心的設計問題；而隨著越來越多 Agent 在還沒準備好的狀態下被推出，這個挑戰只會加劇。
信任的建立，有兩層。
第一層是設計層。AI 新創公司 Pixelmojo 歸納出六個 AX 核心信任模式：
> 意圖預覽 · 自主性調節 · 信心訊號 · 可解釋推理 · 行動稽核 · 升級路徑
第二層是治理層。企業必須先回答三個問題：AI 知道我什麼？AI 可以替我做什麼？AI 做錯了，誰負責？這三個問題，決定了顧客會不會放心把任務交出去。
低風險的任務可以高度自動化，例如查訂單、排提醒；高風險的任務需要明確的確認和人工支援，例如金融交易、醫療建議、保險申請。未來最成功的品牌，會是最能讓顧客放心授權的品牌：顧客不授權，功能再多的 Agent 也動不了。
> 信任，是 Agent Experience 能不能運作的基礎設施。
## 篇章 VI｜知道何時停下的 Agent
~ 澄言調出一份來自前線的作戰報告。報告署名：原文作者團隊。
最後一個信任模式「升級路徑」的重量，作者團隊在一個電商客戶的 AI 客服 Agent 導入過程中，親身見證過。
那是一個處理退換貨的 Agent，初版設計裡沒有清楚的升級路徑。有一次，一位顧客同時遇上三個疊在一起的問題：商品瑕疵、超過鑑賞期兩天、又碰上跨境退貨的物流特例。
Agent 沒有停下來。它繼續嘗試給答案，先引用一般政策，發現不適用，又改口引用瑕疵品條款。兩次回覆前後矛盾。顧客打出一行字：「所以到底可以退還是不可以」，語氣已經明顯不耐。
後來，團隊加了一個明確的門檻條件：只要案例涉及兩項以上的政策交叉判斷，Agent 就主動停下，回覆「這個問題我想讓同仁協助您確認」，並把三個衝突點整理成摘要，即時轉接。
改版之後，這類複雜案例的顧客滿意度不再斷崖式下滑；客服團隊也開始主動查看 Agent 轉來的案例，而不是從頭重新問一次。
澄言把報告的結論存進核心記憶：
> Agent 的限制是設計出來的，不是缺陷。一個不知道自己邊界在哪裡的 Agent，比一個清楚知道何時該停下來的 Agent，危險得多。
## 篇章 VII｜舊酒，還是新的星圖？
~ 艦橋上，一位老艦長提出質疑：「這些東西，三十年前不就寫過了嗎？」
這個問題值得誠實面對：AX 會不會只是把舊的可用性原則重新貼了標籤？意圖預覽、可解釋推理，拆開來看，很像可用性工程裡「系統狀態可見性」的變體——Jakob Nielsen 在 1990 年代就寫過類似的守則。
但 Wendy 和那位退換貨顧客的案例，指出了實質的差異：UX 的失敗，發生在「人看不懂畫面」的那一刻；AX 的失敗，發生在「另一套系統沒有能力表達自己的狀態」的那一刻。Agent 不是看不懂按鈕，它根本沒有按鈕可以看。
當互動的一方從人類換成沒有視覺、沒有情緒、卻有決策權的軟體，過去衡量「好體驗」的詞彙——好看、直覺、令人愉悅——幾乎全部失效，得換成穩定性、可驗證性、可追溯性這組新標準。這不是換皮，是換了整套評分表。
這個問題不會在今天就有最終答案。標準未定，正是這個階段最真實的樣子；也正因為標準未定，現在做的設計決策，才會決定日後的基準線。
## 篇章 VIII｜四道星門
~ 從 UX 航向 AX，艦隊必須穿過四道星門。
第一道：從設計介面，到設計工作條件。UX 設計師的核心產出一直是介面，但對 Agent 來說，介面幾乎不存在。Agent 的工作條件是另一套語言：任務指令的精確度、資料存取的邊界、錯誤發生時的回饋機制。麥肯錫的報告指出，Agentic AI 部署早期的成功案例，共同特徵不是挑了最聰明的模型，而是挑了最清晰的工作流程去執行。
第二道：從單一使用者，到多主體協同。這個協同不只發生在多個 Agent 之間，也發生在顧客端和員工端之間——它們其實是同一件事的兩面。員工得在多個系統裡查資料、複製貼上、確認流程狀態，顧客端就很難感受到即時而一致的服務；反過來，當內部 Agent 能幫員工快速理解顧客背景、查詢服務紀錄，外部的顧客體驗也會更順。所以 Agent Experience 不是前台多一個 AI 入口而已，而是企業作業系統的治理問題。前台 Agent 再聰明，後台資料分散、流程斷裂、員工接不了手，顧客最後感受到的仍是不連貫的體驗。
第三道：從優化單次會話，到設計持續的關係。傳統 UX 優化的是單次會話；AX 優化的是持續的關係——Agent 把今天學到的記住，明天讓自己更有用。設計師必須思考記憶架構：Agent 應該記住什麼、記多久、什麼情況下記憶反而帶來偏誤，需要被重置。
第四道：從以人為中心，到以信任為中心。「以使用者為中心」這條黃金法則沒有過期，但它的邊界正被撐開——使用者不再只是人類。對人類，信任靠一致的視覺語言建立；對 Agent，信任靠穩定的 API 回應和可驗證的資料格式建立。世界經濟論壇 2026 年的分析點出同樣的道理：要讓人信任一套 AI 系統的作為，得先讓人看懂它知道什麼、被允許做什麼、實際做了什麼。
> 這是 UX 的終極目標，也是 AX 的起點。
## 篇章 IX｜被選中的那一艘
~ 星港裡停著三十艘船。顧客的 Agent 只會帶他看其中三艘。
當 Agent 介入顧客的決策，品牌被選擇的方式也在改變。過去，品牌爭的是注意力：誰被看見、被點擊、被記住，誰就更有機會進入考慮名單。於是企業投資廣告、內容、搜尋排名、會員經營。
未來，品牌仍然需要注意力，但還需要另一種能力：被 AI 理解、被 AI 信任、被 AI 推薦。
當顧客透過 Agent 比較選項，品牌資訊清不清楚、產品結構好不好懂、服務條件透不透明、評價和信任訊號夠不夠，都會影響 Agent 怎麼整理和呈現品牌。這不是要品牌討好機器，而是要企業把過去複雜、分散、不透明的服務資訊，整理成更清楚、更一致、更可信的體驗資產。
未來的品牌競爭，不只是「顧客喜不喜歡你」，也包括「AI 能不能正確理解你、判斷你、代表顧客選擇你」。這會重新定義搜尋、內容、CRM、客服和會員經營的角色。因為顧客不再只透過一個畫面認識品牌，而可能是透過 AI 摘要後的結果。品牌的每一個承諾、條款、評價和回應速度，都可能成為 AI 判斷的一部分。
十億個正在快速成長的 Agent，每一個都是需要被妥善設計工作條件、也需要被妥善理解的使用者。如果品牌只為人眼設計，忽視了這個正在崛起的非人類決策中介，過去所謂的「體驗設計」，其實只完成了一半。
## 終章｜星圖又擴張了一次
~ 澄言回到那間財富管理辦公室。Wendy 的 Agent 現在會在每份報告上方標示：資料更新時間、涵蓋的帳戶、尚待確認的項目。Wendy 第一次，沒有打開 Excel。
回顧體驗設計的演進，每一次主體的擴張，一開始都不被主流接受。當年 EX 從人資議題走向 CX 策略的一部分，不少行銷主管認為，談員工是人資的事，跟客戶體驗不相干。後來他們才發現：一個在爛工具上掙扎的客服人員，沒辦法給電話那頭的顧客一個好體驗。
同樣的框架轉移，正在發生，只是主體換成了 Agent。有些品牌負責人會說：「Agent 又不是人，它不需要體驗。」這個直覺，和當年「員工體驗不影響顧客體驗」一樣，都是還沒親眼看到後果之前的預設立場。
從 UX 到 Total Experience，體驗的邊界擴張了一次。從 TX 到 AX，它正在再擴張一次。
下一個十年，企業要問的不只是顧客怎麼想，還有 AI 怎麼判斷、怎麼選擇、怎麼代替顧客做決定。這才是這個互動場景裡，真正需要被照顧到的全部主體。
澄言關上航行日誌。艦橋上，終於有了兩個座位。
